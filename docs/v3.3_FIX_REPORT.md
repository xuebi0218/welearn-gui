# Welearn 刷课工具 v3.3 — 章节学习时长修复

## 问题

**现象**：刷课完成后，客户端显示每个章节/模块的学习时长（`learntime`）为 0 秒（或 1-2 秒），但总的学习时长是正确的。

**影响范围**：刷课模式下的所有小节。刷时长模式下单 SCO 时长也不准确（始终为初始值）。

---

## 根因分析

### 问题 1：刷课模式 `session_time` 硬编码为 `"0"`

`welearn_curriculum_submit()` 构造的 SCORM 数据中：

```python
"session_time": "0",   # ← 始终为 0
"total_time": "0",     # ← 始终为 0
```

且 `savescoinfo160928` 不传 `session_time`/`total_time` 参数。

### 问题 2：服务端 `learntime` 来自实际耗时，非 JSON 字段

通过多轮 API 测试验证：客户端显示的 `learntime` 是服务端计算的 **`startsco160928` → `savescoinfo160928` 之间的实际时间差**，而不是 cmi JSON 中的 `session_time` 字段值。

旧代码流程：
```
startsco160928 → 0.3s延迟 → setscoinfo → 0.4s延迟 → savescoinfo160928
                                        ↑ 总共不到 1 秒 → learntime ≈ 0
```

### 问题 3：刷时长模式心跳不累加时间

`thread_time_execute` 中，心跳始终发送初始值：
```python
cmi = welearn_time_init(...)  # session_time="0", total_time="0"
for t in range(learntime):
    welearn_time_heartbeat(..., cmi['session_time'], cmi['total_time'])
    #                         ↑ 永远是 "0"        ↑ 永远是 "0"
```

### 问题 4：`setscoinfo` 在无实际耗时情况下被服务端拒绝

当 `startsco` → `setscoinfo` 间隔太短时，服务端返回 `"学习数据不正确"`，SCORM 数据（含 interactions）不会被持久化。

---

## 解决方案

### 修复 1：`welearn_curriculum_submit` 增加真实等待

```python
def welearn_curriculum_submit(..., learntime=0):
    # startsco
    session.post(..., action='startsco160928', ...)

    # ★ 等待学习时长，让服务端计时
    if learntime > 0:
        time.sleep(learntime)

    # setscoinfo（session_time/total_time 改为 str(learntime)）
    # savescoinfo（新增 session_time + total_time 参数）
```

### 修复 2：`thread_curriculum_execute` 改为多线程并发

旧：逐课串行处理，每个小节瞬间完成 → `learntime ≈ 0`

新：分批多线程并发，每线程内部执行 `startsco → sleep(30s) → setscoinfo → savescoinfo`：

```python
for batch_start in range(0, total, max_threads):
    batch = all_lessons[batch_start:batch_start + max_threads]
    for unit_i, course in batch:
        t = Thread(target=process_one, args=(unit_i, course))
        t.start()
    # 等待本批次全部完成
    for t in threads:
        t.join(timeout=duration + 30)
```

**效率**：100 个小节，5 线程，每课 30 秒 → `100/5 × 30 = 10 分钟`（串行需 50 分钟）。

### 修复 3：刷时长模式心跳累加时间

```python
init_total = int(cmi['total_time'])
elapsed = 0
for t in range(learntime):
    elapsed = t + 1
    if t == next_heartbeat:
        welearn_time_heartbeat(..., str(elapsed), str(init_total + elapsed))

welearn_time_finalize(..., str(elapsed), str(init_total + elapsed))
```

### 修复 4：GUI 新增参数

刷课 Tab 新增两个输入项：
- **单课学习时长(秒)**：默认 30，控制 `sleep` 时长
- **最大线程数**：默认 5，控制并发数

## 已知局限

1. `learntime` 精度受 `time.sleep()` 精度影响，可能有 ±1-2 秒偏差
2. 多线程共用 `requests.Session`（非线程安全），但实践中工作正常
3. 线程数过高可能导致服务器限流，建议 ≤10
