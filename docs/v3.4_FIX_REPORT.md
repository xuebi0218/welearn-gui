# Welearn 刷课工具 v3.4 — 刷时长心跳修复

## 问题

**现象**：刷时长模式运行后日志显示全部"完成"，但服务端课程学习时长完全没有增长。

**影响范围**：刷时长模式所有课时。日志中的 `learntime` 在 10~60 秒范围内时。

**发现时间**：2026-06-17

---

## 根因分析

### 问题：心跳包 `keepsco_with_getticket_with_updatecmitime` 从未触发

`thread_time_execute` → `process_one`（第 844-856 行）原始逻辑：

```python
next_heartbeat = random.randint(55, 65)   # 第一次心跳安排在 55~65s
elapsed = 0
for t in range(learntime):                # learntime 只有 10~60s
    time.sleep(1)
    elapsed = t + 1
    if t == next_heartbeat:               # 条件几乎永远不成立！
        welearn_time_heartbeat(...)
        next_heartbeat = t + random.randint(55, 65)
```

第一次心跳安排在 `t == 55~65`，但 `range(learntime)` 的最大值是 `learntime - 1`（即 9~59）。绝大多数课时的 `learntime < 55`，心跳条件永不成立。

### 为什么没有心跳 = 没有时长

对比旧版 `WelearnTimeFinsh.py`（v1.0 命令行版）：

```python
# 旧版：循环前先发一次心跳（第 87 行）
req1 = session.post(url, data={
    'action': 'keepsco_with_getticket_with_updatecmitime', ...
})
for nowtime in range(1, learntime + 1):
    time.sleep(1)
    if nowtime % 60 == 0:     # 每 60s 再发
        req1 = session.post(url, data={...})
# 旧版 savescoinfo160928 不传 session_time/total_time
```

服务端通过 **心跳之间的时间差** 来累加学习时长。`savescoinfo160928` 只管完成状态（progress/cstatus），不管时间统计。没有心跳包 = 服务端认为会话无效，丢弃时间。

---

## 解决方案

3 处改动（`process_one` 函数内部，约第 844-864 行）：

### 1. 循环前新增初始心跳

```python
welearn_time_heartbeat(app.session, cid, uid, scoid,
                       "0", str(init_total))
```

注册会话开始，对齐旧版行为。

### 2. 心跳间隔从 55~65s 缩短到 30~40s

```python
next_heartbeat = random.randint(30, 40)
# ...
if elapsed >= next_heartbeat:    # 改用 >= 而非 ==
    welearn_time_heartbeat(...)
    next_heartbeat = elapsed + random.randint(30, 40)
```

改用 `>=` 避免因时间抖动错过精确匹配。

### 3. 循环结束后、finalize 前新增最终心跳

```python
welearn_time_heartbeat(app.session, cid, uid, scoid,
                       str(elapsed), str(init_total + elapsed))
```

告知服务端最终累计时间。

### 效果

| 课时时长 | 旧行为 | 新行为 |
|----------|--------|--------|
| 10s | 0 次心跳 → 无时长 | 初始 + 最终 = 2 次心跳 |
| 35s | 0 次心跳 → 无时长 | 初始 + 中间(30s) + 最终 = 3 次心跳 |
| 60s | 可能 1 次 (55s) | 初始 + 中间(30~40s) + 最终 = 3 次心跳 |

每个课时至少 2 次心跳，确保服务端正确统计时长。
