# v4.0 更新说明

## 做了什么

### 1. 新增「只刷课」模式

三种模式现在是并列的：

| 模式 | 做什么 | 单节耗时 | 适合场景 |
|---|---|---|---|
| 刷课并计时 | 做题 + 答题记录 + 补齐学时 | 按平台要求（通常 30 分钟） | 要学时、要完成度 |
| **只刷课** | 只做题、只写答题记录，不补学时 | 30~45 秒 | 先把完成度顶上去，学时后补 |
| 仅刷时长 | 心跳保活补学时，不动题目 | 按差额 | 已做过题，只缺时长 |

「只刷课」走的还是完整链路：`startsco` → 等最短在线时间 → `setscoinfo`（答题记录）→ `savescoinfo` →
回读校验。区别只是**不把 `learntime` 补齐到 `timelitsec`**，所以平台看到的是「完成得快但时长不足」，
不会被当成「秒完成还学满了」——后者才是复核重点。

### 2. 进度区重做

旧版只有一条进度条和一个数字，看不出卡没卡。新版是一张总览卡：

```
运行状态                         运行中
35%   进度 6/17 · 剩余 11 个
────────────────────────────────────────
已完成 6 · 进行中 4 · 待处理 0
● L1 05. Task 1     ▬▬▬▬▬░░░  35%  07:00/20:00
◆ L2 06. Task 2     ▬▬░░░░░░  20%  心跳超时 55s
● L3 08. Exercise II ▬▬▬▬▬▬▬░  95%  19:00/20:00
● L4 13. Exercise V  ▬▬▬▬▬▬▬▬  98%  19:40/20:00
L2 45 秒无心跳 · 超过 2 分钟可停止重试该节
```

- 总进度按**节数**算（不是时长），语义不会随课时长短漂移
- 每一路一行：状态点 / 节名 / 单节进度条 / 条外百分比 / 已学时长 vs 要求时长
- 状态色：蓝=学习中，琥珀=心跳超时，深琥珀=疑似中断，绿=完成
- 卡住不再靠猜：45 秒没有心跳就变色并在底部提示
- 结束后出对账卡：本次入账多少秒、成功/失败/跳过的节数、失败项可以只重跑

### 3. 顺手修的

- 单节上限从进度区挪到「时长与并发」——设置项不该埋在运行态里
- 模式切换时正确率面板位置错乱（会插到别处去）
- 滚动区域高度不刷新，导致进度卡在窗口底部看不到
- 窄窗口下长文案被裁（并发提示、时长提示都缩短了）

## 怎么用

1. Cookie 登录 → 拉课程 → 选单元
2. 选模式：一般先跑一次「只刷课」把完成度做上去，再用「刷课并计时」补学时
3. 节奏选「安全」、并发 3~4，点开始，进度卡会自己滚出来

## 没变的边界

- 时长是平台按墙钟给的，客户端说什么不算
- 单个 SCO 的学时上限就是 `timelitsec`，跑满了再跑也不会多
- 客观题一节课只能提交一次，答错了不可逆
