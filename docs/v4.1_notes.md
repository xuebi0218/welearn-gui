# v4.1 更新说明 —— 进度条重做

## 为什么换掉原生进度条

CustomTkinter 的 `CTkProgressBar` 只能给一个纯色，圆角是控件自己画的矩形，做不出渐变、光点、刻度。
所以这部分改成用 PIL 逐像素画一张小图，贴到 `tk.Canvas` 上——完全可控，也不引入新依赖（PIL 本来就有）。

## 画了什么

| 元素 | 做法 |
|---|---|
| 胶囊轨道 | 圆角矩形 + 1px 内描边，深蓝 `#1a2942` / 边 `#2a3f63` |
| 渐变填充 | 横向三段插值：青 `#4cc9d6` → 靛 `#5b8def` → 紫 `#8b7cf0` |
| 圆柱高光 | 上半部分叠 20% 白色圆角条，做出"玻璃管"的体积感 |
| 末端光点 | 当前进度处一个白点，跟手移动 |
| 节数刻度 | 总条按总节数切分（>48 节不画，太密看不清） |
| 补间动画 | `set()` 走 14 步 ease-out，约 220ms 到位，不打突跳 |

## 状态配色

| 状态 | 渐变 |
|---|---|
| 正在学习 | 青 → 靛 → 紫 |
| 超过 45 秒无心跳 | 琥珀 → 橙 → 深橙 |
| 超过 120 秒疑似中断 | 砖红 → 深红 |
| 已完成 | 青绿 → 蓝绿 |

颜色不是唯一信号：状态点形状也在变（● 正常 / ◐ 等待 / ◆ 异常），色盲也能分辨。

## 尺寸

- 总进度条：高度 14px，圆角 7px
- 单节进度条：高度 8px，圆角 4px，宽度 136px

## 实现备注（给后来改代码的人）

1. `tk.Canvas` 内部用 `self._w` 表示 widget 路径，所以自定义属性一律加 `b` 前缀（`_bw/_bh/_br/_bcur/...`），
   否则会和 tkinter 的 `_w` 撞名，报 `unsupported operand type(s) for -: 'int' and 'str'`。
2. `Image.paste` 是**替换**像素（含 alpha），不是混合。叠半透明高光必须用 `Image.alpha_composite`，
   最后 `convert("RGB")` 再交给 `ImageTk.PhotoImage`，否则画出来是透明/发黑。
3. 只有 `set()` 触发重绘；`set_ticks()`/`set_colors()` 也各自重绘一次，别在每帧循环里调。
