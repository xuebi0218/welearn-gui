# Welearn 刷课工具 v3.2 — 答题记录修复

## 问题

**现象**：刷课完成后，小节显示"已完成"打勾，但点进去看不到逐题作答记录（提交时间、选项、得分等为空）。

**影响范围**：所有计分小节（`isscored: true`），如 Lead-in、Task、Exercise 等。非计分小节（Unit Goals、Quotation 等）不受影响。

---

## 根因分析

### `[INTERACTIONINFO]` 不是占位符，是分隔符

从 v0.7dev 到 v3.1，`setscoinfo` 提交的 data 一直是这样拼的：

```python
data = '{"cmi":{...}}' + '[INTERACTIONINFO]'  # 字面量拼接！
```

表面上看像是遗留的占位符，实际上服务器端约定的格式是：

```
{SCORM_JSON数据}[INTERACTIONINFO]{题目作答详情}
```

### 前端 JS 确认了这一点

从 `StudyCourse.aspx` 页面提取的真实代码：

```javascript
// 第 51480 行
var interactionsInfo = GetInteractionInfo(apiObj);

// 第 51910 行
data: jsonStr + '[INTERACTIONINFO]' + interactionsInfo,
```

### `GetInteractionInfo()` 逆向

```javascript
function GetInteractionInfo(apiObj) {
    var interactionsInfo = '';
    var cmiInterCount = parseInt(apiObj.GetValue("cmi.interactions._count"));
    for (var i = 0; i < cmiInterCount; i++) {
        // 格式: $$编号[]是否分享[]是否难题[]escape(答案)[]批阅结果
        interactionsInfo += '$$' + i + '[]' + isshared + '[]' + isdifficult + '[]'
                         + escape(learner_response) + '[]' + result;
    }
    return interactionsInfo.substring(2); // 去掉开头的 $$
}
```

即 `interactionsInfo` 格式为：

```
0[]false[]false[]%u4F60%u597D[]correct$$1[]false[]false[]B[]wrong
```

### 题目和答案的来源

SCO 内容是 AngularJS SPA，题目和正确答案存在 HTML 模板中：

- `scoAddr` API 返回内容 URL：`//centercourseware.sflep.com/.../index.html#/2/4-3`
- 模板路径：`data/2/4-3.html`（从 hash 路由解析）
- 题型标记：
  - `<et-blank g>正确答案</et-blank>` — 填空题，`g` = 正确答案
  - `<et-tof key="t">` — 判断题，`key` 为 `t`/`f`
  - `<et-choice key="A">` — 选择题，`key` 为正确答案

### v3.1 为什么 API 返回 `ret:0`

服务器端 `setscoinfo` 接收数据后按 `[INTERACTIONINFO]` 分割。前半部分 JSON 解析成功、后半部分为空，服务器**不报错但不生成答题记录**。所以 API 一直返回成功，但实际没有记录。

## 解决方案

### 新增 5 个函数（~130 行）

| 函数 | 作用 |
|------|------|
| `_js_escape()` | 模拟 JS `escape()` 编码 |
| `welearn_get_sco_addr()` | 调用 `scoAddr` API，从 hash 路由解析模板 URL |
| `_fetch_sco_template()` | 用已认证 session 抓取 SCO HTML 模板 |
| `parse_sco_questions()` | 解析 HTML 中的 `<et-blank g>` + `<et-tof key>` + `<et-choice key>` |
| `generate_interactions()` | 按正确率随机判定每道题对错，生成 `interactions` 和 `interactionsInfo` |

### 重写 `welearn_curriculum_submit()`

新流程：

```
scoAddr → 获取模板URL → 抓取HTML → 解析题目
→ generate_interactions(crate) → 生成完整JSON+interactionsInfo
→ startsco160928 → setscoinfo(含答题数据) → savescoinfo160928
```

返回值改为 3 元组：`(way1_ok, way2_ok, questions_found)`

### 容错设计

- 模板抓取/解析失败 → 退化为空 interactions（不影响提交）
- 非计分小节无题目 → 空 interactions（等同原有行为）
- 所有异常被 try/except 捕获，不中断执行

## 验证结果

用实际 Cookie 测试 `Unit 02 > Listening as Comprehension > 06. Task 2`：

- ✅ 解析出 **19 道题**（14 填空 + 5 判断）
- ✅ 正确率 80% 生成 interactions 数据
- ✅ `setscoinfo` + `savescoinfo` 全部 `ret:0`
- ✅ `getscoinfo_v7` 验证：`comment` 中 `interactions` 从 `[]` 变为含 19 条记录的完整数组

## 已知局限

1. **仅支持 3 种题型**：填空 (`et-blank`)、判断 (`et-tof`)、选择 (`et-choice`)。其他题型（如口语录音、写作等）不会被解析
2. **错误答案生成简单**：选择题只做 A→B 翻转，未模拟真实错误分布
3. **不同课程可能题型不同**：不同出版社/课程的 SCO 模板格式可能有差异
4. **打包后 exe 体积不变**：新增逻辑纯 Python，不引入新依赖
